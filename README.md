## Features Implemented
* **Insert a line:** Add text at a specified line number, shifting existing lines down[cite: 2].
* **Delete a line:** Remove a line at a given number[cite: 2].
* **Display document:** Print all current lines with line numbers[cite: 2].
* **File I/O:** Save and load document content from `.txt` files[cite: 2].
* **Search & Statistics:** Search for keywords and view line/word counts[cite: 2].
